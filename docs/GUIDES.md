# Guides

One page for each topic: what it is for and when to choose it, its variants side by side, every parameter, the usual mistakes, where it is in the application and what an AI agent asks and checks. The [tutorial](TUTORIAL.md) goes step by step through a first model; the [language reference](LANGUAGE.md) lists everything in brief. An agent reads the same pages with `hcad_docs` (format: guide), or `hcad docs --guide NAME`.

- **[Threads](guides/threads.md)**: A real helical thread on a shaft or in a hole: ISO metric, inch, trapezoidal and ACME, buttress, pipe threads, lamp bases, bottle necks. Which one to choose, how to recognise one on a real object, every parameter, and how to print it.
