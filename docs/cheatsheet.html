Objects and types

Solid
A 3D body: boxes, cylinders, booleans, features. Every operation gives a new one.
Profile
A flat 2D outline on XY (rect, circle, text, sketch.profile): extrude or revolve it into a Solid.
Path
A curve in space (path, spline, helix) to sweep a profile along.
Vec
A 2D or 3D vector or point: vec(10.mm, 5.mm, 0.mm); .x .y .z .length.
Vec2
A 2D vector.
Vec3
A 3D vector.
Direction
An axis direction: X, Y, Z, -X…, or any vector.
Plane
An infinite plane: an origin and a normal (XY, plane(…), body.plane(faces.top)); cuts, mirrors, sections.
Axis
A line in space: an origin and a direction (axis(…), body.axis(edges…)); rotations and circular patterns.
Frame
A coordinate system on a face or plane: origin, X, Y and Z (body.frame(faces.top)); placeOn builds on it.
BBox
A solid's bounding box: min, max, size, center.
Split
What split gives: .above (where the plane's normal points) and .below.
Edges
A selection of a solid's edges, for fillet and chamfer: edges.parallel(Z), edges.of(faces.top)…
Faces
A selection of a solid's faces, for shell, draft, frames: faces.top, faces.normal(X)…
Edge
One edge, inside a selector predicate: edges.filter(e => e.isCircle && e.radius == 3.mm).
Face
One face, inside a selector predicate: faces.filter(f => f.center.z > 10.mm).
Sketch
A constrained 2D drawing: points, lines, arcs and constraints; the solver places them, .profile gives the outline.
Drawing
A technical sheet (views, sections, dimensions) returned by a @drawing function; exported as PDF, SVG, DXF.
Assembly
Parts placed by their connections (planned).
Color
A colour: "steelblue", "#RRGGBB", "#RRGGBBAA" or rgb(…).
Length
A length with its unit: 10.mm, 2.5.cm; bare numbers given to geometry are mm.
Angle
An angle: 30.deg, 0.5.rad.
Area
An area (Length × Length).
Volume
A volume.
bool
true or false.
int
An integer.
double
A number.
float
A number.
real
A number.
long
An integer.
string
Text.

import hardware;

struct Screw(name: string, d: Length, pitch: Length, tap: Length, clearance: Length, head: Length, headHeight: Length, key: Length, nut: Length, nutHeight: Length, washer: Length, insert: Length, insertDepth: Length)
Metric screw sizes (ISO 4762 socket head cap screws, ISO 4032 nuts, ISO 7089 washers) with the holes to print or drill for them.
hexPrism(acrossFlats: Length, h: Length) → Solid
Hexagonal prism standing on XY, flats parallel to the X axis.
screw(s: Screw, length: Length, socket: bool = true, threaded: bool = false) → Solid
Socket head cap screw. The underside of the head lies on z = 0: the head grows upwards and the shank downwards, so the screw drops into a hole. threaded: true models the ISO thread (slower); otherwise the shank is plain.
nut(s: Screw, threaded: bool = false) → Solid
Hex nut standing on z = 0, with the corners chamfered on both faces. threaded: true cuts the ISO thread in the hole.
washer(s: Screw) → Solid
Flat washer standing on z = 0.
hole(s: Screw, depth: Length, kind: string = "clearance") → Solid
A hole to subtract, with its top on z = 0 going down `depth`: "clearance" (the screw passes), "tap" (pilot hole for the thread), "insert" (heat-set insert), "counterbore" (clearance with room for the head) or "countersink" (for flat heads).
nutTrap(s: Screw, depth: Length, clearance: Length = …) → Solid
A pocket to trap a nut, from z = 0 going down `depth` (with a little clearance).
M2, M2_5, M3, M4, M5, M6, M8: Screw
